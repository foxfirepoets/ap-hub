## What ralph will build

A graphical installer layer over ap-hub's existing onboarding wizard: a welcome screen naming
both prerequisites, a visual 9-step progress stepper, per-step explainers, graphical blocker
cards, and a friendly-error panel — zero backend/schema/auth changes.

Chunks (5 total):
- CHUNK_1_ERRORHELPERS: extract a pure, testable error-code-to-plain-English mapper
- CHUNK_2_WELCOME: welcome overlay naming both onboarding prerequisites
- CHUNK_3_STEPPER: visual progress stepper across all 9 onboarding steps
- CHUNK_4_EXPLAINERS: per-step prerequisite explainers and graphical blocker cards
- CHUNK_5_INTEGRATION: wire the friendly failure panel into every existing failure path, final gate

```bash
#   ~\.claude\skills\ralph-wiggum-loop\scripts\ralph-loop.ps1 -Auto -MaxIterations 15
```

**In-session mode (used for this build):** run build iterations inside Claude Code — Claude acts
as ORCHESTRATOR and spawns one fresh subagent per chunk via the Agent tool (sequentially), using
these same state files, then independently re-runs the validation gate before committing (never
trusting a subagent's self-report). NEVER run `claude` or the loop scripts through Claude Code's
Bash tool — that nests a Claude session inside a Claude session.
