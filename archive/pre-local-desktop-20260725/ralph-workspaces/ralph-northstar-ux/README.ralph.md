## What ralph will build

A Next.js human product layer over the existing ap-hub pipeline — Google-SSO login with 3 roles, a read/action API that calls existing services (never a second QBO-write or send path), the core screens (Today, Exceptions, Transactions, Evidence, Onboarding dry-run), and a daily digest.

Chunks (7 total):
- CHUNK_1_AUTH: Add Google-SSO login with tenant-scoped, role-based sessions.
- CHUNK_2_SERVICES: Extract a shared service layer that both the CLI and the API call.
- CHUNK_3_READ: Serve read-only Today, Exceptions, Transactions, Evidence, and Audit data.
- CHUNK_4_ACTION: Expose role-gated approve/reject/remap/learn/retry/reply routes over the service layer.
- CHUNK_5_FRONTEND: Build the Next.js shell, core pages, and shared Evidence panel.
- CHUNK_6_ONBOARDING: Guide first-run setup with a dry-run that posts nothing.
- CHUNK_7_DIGEST: Generate a daily digest and immediate risk alerts, reusing the severity classifier.
