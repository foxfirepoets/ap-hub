## What ralph will build

The buildable foundation of a cross-platform, provider-neutral AP automation platform: a key broker holding Ben's Claude+SwarmSync keys (so no tester machine does), the provider-neutral `AccountingConnector` seam proven by wrapping the existing QuickBooks Online code, the OS-neutral `HostAdapter` seam (Windows now, macOS compiled), and a non-elevated Windows pilot harness with a watchdog and liveness telemetry.

Chunks (8 total):
- CHUNK_1_BASELINE: prove the 212-test green baseline and fix the OAuth port drift
- CHUNK_2_BROKERAUTH: broker service skeleton with per-install token auth
- CHUNK_3_BROKERPROXY: fail-closed Claude+SwarmSync proxy with spend caps
- CHUNK_4_BROKERMODE: rewire ap-hub to the broker, keys optional, proof calls hold on outage
- CHUNK_5_CONNECTOR: provider-neutral connector + canonical model (QBO reference, no-leak lint)
- CHUNK_6_TELEMETRY: liveness telemetry + pilot-report, no business data
- CHUNK_7_HARNESS: cross-platform host adapter + non-elevated Windows install & watchdog
- CHUNK_8_DEPLOY: deploy the broker to Render, roll out to one real machine

```bash

# Step 3 — Build loop (bounded):
```
